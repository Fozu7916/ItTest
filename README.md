## 📌 О проекте

Большинство тестов на профориентацию в сети работают по примитивной логике. Этот сервис использует взвешенную систему баллов, оценивая предрасположенность пользователя к **14 различным IT-направлениям** (Backend, Frontend, ML, DevOps, QA, GameDev и др.).

Проект создан как лид-магнит и полезный инструмент для начинающих разработчиков в рамках концепции **Build in Public**.

### ✨ Фичи
- ⚡ **Быстрый тест (15 вопросов):** Экспресс-анализ для определения топ-3 направлений.
- 🎯 **Полный тест (50 вопросов):** Глубокий анализ хард/софт скиллов и интересов по всем 14 областям.
- 📊 **Прозрачная математика:** Результат выдается в виде таблицы баллов, а не абстрактного ярлыка.
- 🚀 **SPA:** Полностью клиентское приложение, работает без бэкенда, мгновенный отклик.

## 🛠 Технический стек

- **Core:** React, TypeScript
- **Build Tool:** Vite
- **Deployment:** Netlify
- **Architecture:** Компонентный подход, чистая логика подсчета стейтов.
