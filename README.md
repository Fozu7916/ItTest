## 📌 About the Project

Most online career guidance tests operate on primitive logic. This service uses a weighted scoring system to assess a user's aptitude for **14 different IT areas** (Backend, Frontend, ML, DevOps, QA, GameDev, etc.).

The project was created as a lead magnet and a useful tool for aspiring developers within the **Build in Public** concept.

### ✨ Features
- ⚡ **Quick Test (15 questions):** A quick analysis to determine the top 3 areas.
- 🎯 **Full Test (50 questions):** An in-depth analysis of hard and soft skills and interests across all 14 areas.
- 📊 **Transparent Math:** The result is presented as a score table, not an abstract label.
- 🚀 **SPA:** A fully client-side application, works without a backend, with instant response.

## 🛠 Tech Stack

- **Core:** React, TypeScript
- **Build Tool:** Vite
- **Deployment:** Netlify
- **Architecture:** Component-based approach, clean state calculation logic.
